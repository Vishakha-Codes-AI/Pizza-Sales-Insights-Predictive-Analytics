# 🍕 Pizza Sales Insights & Predictive Analytics

An end-to-end data analytics and data science project designed to analyze pizza store sales performance, understand customer purchasing behavior, and forecast future demand.

## 🛠️ Tech Stack & Tools
* **SQL:** Data cleaning, transformation, and extracting core business KPIs (Total Revenue, Avg Order Value).
* **Power BI:** Designing an interactive dashboard for executive-level business tracking.
* **Python:** Predictive analytics, trend visualization, and future demand forecasting.
* **Canva:** Business storytelling and stakeholder presentation.

---

## 📁 Repository Structure
* **[01_Data](./01_Data):** Contains the 4 raw Excel/CSV datasets (Orders, Order Details, Pizzas, Pizza Types).
* **[02_SQL_Queries](./02_SQL_Queries):** Clean and well-commented SQL scripts solving key business problems line-by-line.
* **[03_Python_Analysis](./03_Python_Analysis):** Jupyter notebook containing the predictive analytics code and the generated demand forecast graphs.
* **[04_PowerBI_Dashboard](./04_PowerBI_Dashboard):** The main `.pbix` dashboard file along with static screenshots.
* **[05_Presentation](./05_Presentation):** A backup PDF copy of the project presentation slides.

---

## 📊 Key Insights & Business Findings
1. **Peak Order Hours:** Peak sales occur between 5:00 PM and 8:00 PM, suggesting a need for optimized kitchen staffing during these hours.
2. **Top Revenue Generator:** The 'Classic' pizza category drives the highest overall revenue contribution.
3. **Predictive Forecasting:** Based on the Python analysis model, pizza demand is projected to increase by 15% over the upcoming month.
